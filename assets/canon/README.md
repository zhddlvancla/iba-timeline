사용자 제공 컨셉아트는 원본 크기와 비율을 유지한 WebP로 저장한다. 이전 관리국 복장·직책 통합 도판은 새 요원 설정에 따라 폐기했다. 총람 정본과 앱 내장 원문은 같은 상대 경로를 사용하고, 렌더러가 앱 기준 경로로 해석한다. 루미나 도판은 제한 열람 해제 조건을 따른다.

서고 두 측량·제0열람실 사진도 정본 Markdown에 명시한다. 앱 전용 자동 삽입을 사용하지 않으며, 정본과 앱에서 같은 도판 목록을 유지한다. 제03장 조직 도판 6장과 제10장 루미나 복장 도판 3장은 2026-11-12에 삭제했다.
