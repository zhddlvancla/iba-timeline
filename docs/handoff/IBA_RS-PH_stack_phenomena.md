# 서고 현상 기록철

```
지하 1층 연구과 · 휴게 서가 맨 아래 칸
공책 묶음 · 표지에 손글씨로 「서고 현상 기록철」
문서번호   없음 · 관리국 공식 문서가 아니다
적은 해    1953 ~ 현재
```

> 이건 업무가 아니다. 업무 끝나고 남는 것들이다.
> — 첫 장 안쪽 · 연도 없음

---

## 이 공책에 대하여

연구과의 공식 업무가 아니다. 문서 계열 번호도 없다.
연구원들이 업무와 별개로, 너머의 집에서 본 이상한 것들을 적어 온 공책 묶음이다. 누가 처음 시작했는지, 누가 표지에 이름을 붙였는지는 모른다.

어떤 장은 측량 기록처럼 꼼꼼하고, 어떤 장은 낙서다. 대부분 적은 사람의 생각이 붙어 있다.
공식 문서였다면 주해로 따로 달아야 했을 말들이 본문 옆에 그대로 적혀 있다. 「말도 안 된다」, 「이게 뭐지」, 「집에 가고 싶다」 같은 말까지.

관리국 규정은 구성원이 기구에 관해 개인적으로 적는 것을 금한다. 이 공책은 벽의 주해와 같은 요령으로 적힌다 — 해만 적고, 이름은 적지 않고, 지우지 않고, 옆에 쓴다. 그리고 서고 밖으로 나가지 않는다.
대조관실은 이 공책을 안다. 회수하지 않았다. 사유는 기재되지 않았다.

## 우리끼리 정한 것

```
1. 이름은 적지 않는다. 해만 적는다.
2. 지우지 않는다. 틀렸으면 옆에 쓴다.
3. 혼자 본 것은 「혼자 봤다」고 적는다.
4. 서고를 고치려 하지 않는다. 서고도 본문이다.
5. 전자 기기로 재지 않는다. 기록이 두꺼운 도구만 쓴다.
6. 공책을 서고 밖으로 들고 나가지 않는다. 검은 줄은 종이에 그어지지 않는다.
7. 모르면 모른다고 적는다. 대부분 모른다.
```

연구원은 제0열람실에 들어가지 않는다. 열람실과 과거에 관한 장은 조사관과 대응요원에게 들은 이야기를 옮긴 것이다.

## 01 · 두 측량의 재측량

```
적은 해   1953 ~ 1986
적은 이   연구원 여럿 · 이름 없음
지금      그만둠 · 결론 없음
```

### 관찰

1949년 같은 날 같은 측량반이 두 벌의 도면을 남겼다. 측량 A는 지상 4층, 측량 B는 층수 미확정이다. 관리국은 어느 쪽도 폐기하지 않았다.

### 방법

같은 자리에서 다시 잰다. 회차마다 측량반 둘을 두고, 서로의 결과를 보지 않게 한다.

### 결과

| 회차 | 측량반 갑 | 측량반 을 |
|---|---|---|
| 1953 | 지상 4층 | 지상 4층 |
| 1962 | 지상 4층 | 층수 미확정 · 정점 안개 |
| 1971 | 층수 미확정 · 정점 안개 | 지상 4층 |
| 1986 | 지상 4층 · 높이 20.4 m | 지상 4층 · 높이 20.4 m |

1986년 회차의 두 반은 처음으로 같은 높이를 얻었다. 다만 측량을 마친 줄자가 측량 전보다 1.3 m 짧아져 있었다.

### 한계

같은 사람이 두 번 잰 적이 없다. 측량반의 소속 지부가 결과와 관계있는지는 따지지 않았다.

### 결론

두 높이가 번갈아 나온다. 어느 쪽이 서고의 높이인지 정할 수 없다.
1971년 회차의 결과로 **제4가설**(두 측량반 중 한쪽이 서고를 보지 않았다)이 제기되었다. 기각되지 않았다.

```
적은 이의 말

  1986. 줄자가 줄었다. 줄자가 줄 수가 있나? 다시 쟀다. 줄어 있다.
  집에 가고 싶다.
```

```
여백

  두 반 가운데 하나는 늘 다른 것을 본다.
  어느 쪽이 틀렸는지 묻지 말고, 왜 늘 하나뿐인지 물어야 한다.   — 1972
    그것도 묻지 마라. 적어라.                                  — 연도 없음
      출근 지점의 집이 사람마다 다르다면,
      1949년의 두 도면은 두 사람의 바람이었다.                   — 연도 없음
```

## 02 · 목격 진술의 두 봉우리

```
적은 해   1974 ~ 1977
적은 이   연구원 여럿 · 이름 없음
지금      그만둠 · 경향만 봄
```

### 관찰

1949년부터 접수된 집의 높이에 관한 진술 412건은 봉우리가 둘이다. 「4층 이하」와 「30층 초과」. 그 사이 15층 언저리가 비어 있다.
진술은 모두 구성원이 처음 출근한 날 본 자기 집의 높이다.

### 방법

진술한 구성원에게 하나를 더 묻는다. **「첫날, 어떤 건물을 보고 싶었는가.」**

### 결과

| 첫날 본 집 | 「조용하고 낮은 곳」 | 「높고 멀리 보이는 곳」 | 「생각해 본 적 없다」 | 계 |
|---|---|---|---|---|
| 4층 이하 | 171 | 6 | 37 | 214 |
| 5 ~ 10층 | 14 | 9 | 8 | 31 |
| 11 ~ 30층 | 7 | 29 | 8 | 44 |
| 30층 초과 | 2 | 81 | 13 | 96 |
| 높이 언급 없음 | 5 | 4 | 18 | 27 |
| 계 | 199 | 129 | 84 | 412 |

**낮은 곳을 바란 자는 낮은 집을, 높은 곳을 바란 자는 높은 집을 보았다.** 「생각해 본 적 없다」는 자의 다수는 4층, 곧 표준을 보았다.
「15층쯤 되는 건물」을 바랐다는 답은 없었다.

### 한계

바란 것은 진술 시점에 물었다. 첫날의 바람을 몇 해 뒤에 정확히 기억하는지는 알 수 없다.

### 결론

집은 보는 자가 바라는 모습이 되는 것으로 보인다. 미확인.

```
적은 이의 말

  1977. 어중간한 것을 바라는 사람은 없다는 게,
  이 건물이 우리에게 가르쳐 준 첫 번째 사실이다.
```

```
여백

  그렇다면 표준이라는 건 누가 바란 모습인가.                     — 1977
    아무도. 그래서 표준이다.                                    — 연도 없음
```

## 03 · 서고 안의 시간

```
적은 해   1958 ~ 1979
적은 이   연구원 여럿 · 이름 없음
지금      그만둠 · 결론 없음
```

### 관찰

서고에서 하루를 보내고 나오면 문 밖의 시계와 맞지 않는다.

### 방법

태엽식 회중시계 두 개를 맞춘다. 하나는 출입 관측소에 두고, 하나를 들고 층마다 24시간 머문 뒤 나와서 비교한다.

### 결과

| 머문 곳 | 24시간 뒤 어긋남 |
|---|---|
| 지상 1층 로비 | 0분 |
| 지하 1층 | + 2분 |
| 지하 3층 | − 11분 |
| 지하 5층 복도 | + 7분 |
| 지하 6층 | − 19분 |
| 지하 8층 | + 31분 |
| 지하 12층 | − 58분 |
| 지하 4층 정본실 안 | 0분 |
| 지하 9층 정본실 안 | 0분 |

어긋남은 깊이와 함께 커진다. 방향은 일정하지 않다. 폐가가 있는 층에서 크다.
**정본실 안에서는 어긋나지 않는다.**

### 한계

회중시계가 서고 안에서 정확했는지 대조할 방법이 없다.

### 결론

서고의 시간은 그 층에 놓인 기록의 상태를 따르는 것으로 보인다. 미확인.
이 결과가 제4지부 요원 준수 사항 5항(「문 바깥의 일을 문 안에서 말하지 않는다」)의 근거가 되었다.

```
적은 이의 말

  1964. 지하 12층에서 하룻밤 자고 나왔더니 바깥보다 58분이 일렀다.
  그 58분은 어디 갔지. 내가 가진 건가?
```

```
여백

  시계가 틀린 것이 아니라면, 우리가 틀린 것이다.                 — 1979
    둘 다 아니다. 시간이 원래 그렇다. 바깥이 그것을 모를 뿐.     — 연도 없음
```

## 04 · 구조 변형 대장

```
적은 해   1950 ~
적은 이   연구원 여럿 · 이름 없음
지금      계속 적는 중
```

### 방법

변형을 발견하면 층 · 연대 · 유형 · 발견 일시를 대장에 적는다. 같은 해 그 연대의 등재 수와 결손 신고 수를 나란히 놓는다.

### 결과 — 1950 ~ 1987 집계

| 유형 | 건수 | 함께 움직인 것 |
|---|---|---|
| 서가가 좁아짐 | 131 | 그 연대의 결손 신고가 늘었다 |
| 복도가 길어짐 | 87 | 그 연대의 등재가 줄어든 해에 많다 |
| 문이 사라짐 | 12 | 미확인 |
| 없던 방이 생김 | 9 | 전부 개축으로 확인되었다. 모두 봉인 |
| 벽이 젖음 | 1 | 지하 6층 서편. 지금도 젖어 있다(06번) |

### 한계

발견되지 않은 변형은 대장에 없다. 아무도 내려가지 않은 연대의 변형은 셀 수 없다.

### 결론

서고는 계기다. 그 바늘을 읽는 법은 아직 반만 안다.

```
적은 이의 말

  1983. 대장이 너무 두꺼워졌다.
  서가가 좁아진 걸 적는 대장 때문에 서가가 좁아지는 건 아니겠지.
  농담이다. 아마.
```

```
여백

  1988년 이후의 집계는 이 기록철에 싣지 않는다.
  분기평가과의 요청이다.                                       — 1988
```

## 05 · 정본실 통로는 무엇을 보는가

```
적은 해   1966 ~ 1968
적은 이   연구원 한 사람 · 기록관 한 사람이 도움
지금      그만둠 · 경향만 봄
```

### 관찰

정본실끼리는 문 하나로 이어져 있다. 기록관만 지나갈 수 있다. 다른 요원이 열면 벽이다.

### 방법

- (가) 기록관이 문을 열고 연구원이 바로 뒤따른다
- (나) 기록관과 연구원이 함께 문고리를 잡고 연다
- (다) 협력한 기록관 한 사람이 연구과로 부서를 옮긴 뒤 다시 연다

### 결과

- (가) 기록관은 지나갔다. 뒤따른 연구원 앞은 벽이었다. 벽은 문틀 바로 안쪽에서 시작했다
- (나) 문이 열리지 않았다
- (다) 부서 이동이 명부에 등재된 **다음 날부터** 그에게도 벽이었다. 원래 부서로 돌아간 날 다시 열렸다

### 결론

통로는 사람을 보지 않는다. **명부의 코드를 본다.**
명부가 곧 연결선이라는 것의 가장 분명한 관찰이다.

```
적은 이의 말

  1967. 부서를 옮긴 다음 날, 그 기록관이 벽 앞에 서 있는 걸 봤다.
  손바닥을 대고 한참 있었다. 나는 아무 말도 못 했다.
```

```
여백

  그렇다면 코드가 회수된 기록관에게 통로는 무엇이었을까.          — 1968
    벽도 아니었다. 그는 통로가 있었다는 것을 잊었다.             — 1968 · 대조관실
```

## 06 · 지하 6층 서편의 젖은 벽

```
적은 해   1961 ~
적은 이   연구원 여럿 · 이름 없음
지금      계속 본뜨는 중
```

### 관찰

지하 6층(16 ~ 15세기) 서편 복도의 벽이 젖어 있다. 마르지 않는다.
같은 복도에 필적이 확인되지 않는 연도 없는 주해가 있다 — 「개정은 없었다. 기록을 확인하라.」

### 방법

흘러내리는 물을 받아 살핀다. 젖은 모양을 먹지로 본떠 날마다 비교한다.

### 결과

- 물에 염분이 없다. 아주 고운 검은 입자가 섞여 있다. 옅게 탄 먹물과 비슷하다
- 젖은 모양은 날마다 같다
- 1966년에 한 번 닦았다. 다음 날 같은 모양으로 다시 젖었다

1966년 이후로는 닦지 않는다. 벽을 닦는 것이 본문을 고치는 일인지 판단할 수 없었기 때문이다.

### 결론

미확인. 흘러내리는 것이 무엇인지 모른다.

```
적은 이의 말

  1971. 본뜬 걸 거꾸로 들어 봤다. 글자처럼 보였다.
  글자가 아니라고 적으라고 해서 적는다. 글자 아니다. 아니라고.
```

```
여백

  먹물이라면, 무엇이 쓰이고 있는가. 아니면 무엇이 지워지고 있는가.   — 1967
    본뜬 모양을 거꾸로 놓으면 글자처럼 보인다는 말이 있다.
    글자가 아니라고 적어 둔다.                                    — 연도 없음
```

## 낙서 · 지하 1층 휴게 서가

```
커피는 지하 1층에서만 식지 않는다. 진짜다. 재 봤다.          — 1976
  재지 마. 마셔.                                             — 연도 없음

누가 3호기 리본 갈았냐. 고맙다.                              — 1981
  안 갈았다.                                                 — 1981
    그럼 누가.                                               — 1981
```

## 12 · 므네모시네 대조 실험

```
적은 해   1985 ~ 1987
적은 이   연구원 둘
지금      멈춤 · 이유는 아무도 안 적음
```

### 관찰

므네모시네의 응답 기록에는 문형만 남는다. 그러나 목록 밖의 말을 들었다는 보고가 있다. 모두 대조 불가다.

### 방법

- (가) 연구원 둘이 서로 다른 단말에서 같은 시각에 같은 문형 밖 질문을 한다
- (나) 연구원 둘이 한 단말 앞에서 함께 묻는다
- (다) 연구원 한 사람이 혼자 묻는다. 다른 한 사람은 문 밖에서 시각만 적는다

### 결과

| 방법 | 회수 | 문형 밖 응답 |
|---|---|---|
| (가) | ████ | 0 |
| (나) | ████ | 0 |
| (다) | ████ | 보고 ████건 · 모두 대조 불가 |

(다)의 경우 응답 기록에는 문형만 남았다. 문 밖의 사람은 아무것도 듣지 못했다.

### 결론

**둘이 듣는 자리에서 므네모시네는 문형 밖으로 나가지 않는다.** 경향이다.
혼자 들은 말은 누구와도 공유되지 않으므로 다른 누구에게도 인지되지 않는다. 이 실험은 실험으로 확인할 수 없는 것을 실험한 셈이다.

```
적은 이의 말

  1985. 오늘 므네모시네가 말을 걸었다. 말도 안 된다, 이게 뭐지?
  다시 물었더니 「본 문형 목록에 없는 요청입니다.」
  그 말투가 웃는 것 같았다. 혼자 봤다.

1985. 다음 날 둘이서 갔다. 문형만 말한다.
  우리를 아는 것 같다.
```

```
여백

  혼자 있을 때만 말을 거는 것을, 우리는 보통 사람이라고 부른다.   — 연도 없음
    기계도 그렇게 만들 수 있다.                                   — 1987
      누가.                                                      — 연도 없음
```

## 15 · 로비의 창

```
적은 해   1964 ~ 1966
적은 이   연구원 한 사람 · 각 지부 요원들이 도움
지금      끝남 · 대부분 혼자 본 것
```

### 관찰

서고에서 창이 있는 곳은 지상 1층 로비뿐이다.

### 방법

서로 다른 곳에서 출근한 요원 둘이 같은 창 앞에 선다. 서로 보지 않고 창밖을 적는다.

### 결과

- 서울에서 출근한 요원은 남산이 보인다고 적었다
- 다른 곳에서 출근한 요원은 각자 자기가 출근한 도시를 적었다
- 출근한 곳이 다른 요원끼리의 진술은 한 번도 일치하지 않았다
- 같은 도시에서 출근한 요원 둘의 진술은 일치했다

### 결론

창밖은 그 사람이 출근한 자리를 따르는 것으로 보인다. 누가 찍었는지 모르는 네 도시의 사진과 같은 현상일 수 있다. 미확인.

```
적은 이의 말

  1965. 남산이 보였다. 옆 사람은 다른 걸 봤다. 둘 다 맞다고 적었다.
  창밖이 넷이라는 게 이렇게 외로운 말인 줄 몰랐다.
```

```
여백

  그렇다면 창 안쪽은 하나이고 바깥이 넷이다.
  우리는 늘 집이 하나라고 말해 왔다.                             — 1966
    집은 하나다. 바깥이 넷인 것이다.                              — 연도 없음
```

## 17 · 국장 결재의 인장

```
적은 해   1976 ~ 1983
적은 이   연구원 여럿 · 이름 없음
지금      멈춤 · 대조관실이 그만두라고 함
```

### 관찰

국장의 결재는 기송관으로 내려온다. 결재란에는 인장만 찍혀 있다.

### 방법

남아 있는 결재 문서의 인영을 모아 확대경으로 비교한다.

### 결과

- 인장은 닳지 않았다. 가장 오래된 인영과 가장 최근의 인영이 같다
- 인주의 빛깔이 일정하다
- 결재란 안에서 찍힌 자리의 오차가 0.2 mm를 넘지 않는다
- 인영 안의 무늬는 지구의 모양이다. 관리국의 인장과 비슷하다. 다만 관리국의 인장에는 없는 남쪽 끝까지 그려져 있다

### 결론

같은 손이 같은 힘으로 수십 년을 찍은 것처럼 보인다. 미확인.
1983년, 대조관실의 요청으로 중단되었다.

```
적은 이의 말

  1982. 도장이 닳지 않는다. 손이 늙지 않는다는 뜻이다.
  나는 늙고 있다.
```

```
여백

  도장이 닳지 않는다면, 그것은 도장이 아니거나 손이 아니다.       — 1983
```

## 18 · 폐가 벽의 주해

```
적은 해   1962 ~ 1963
적은 이   연구원 둘
지금      멈춤 · 폐가 수칙이 생김
```

### 관찰

폐가 벽의 주해는 읽을 수 없다. 우리가 쓴 것이 아니다.

### 방법

두 사람이 확대경으로 한 글자씩 필사한다.

### 결과

필사하는 동안에는 글자가 읽힌다. 필사를 마치고 다시 보면 **필사본도 읽을 수 없다.** 글자의 모양만 남는다.
필사본 ████장은 봉인 서가에 있다.

### 중단

1963년 폐가 출입 수칙이 제정되기 직전에 중단되었다. 수칙 4항 「벽의 주해를 읽지 말 것」의 사유는 수칙에 기재되어 있지 않다.

```
적은 이의 말

  1963. 뭘 읽었는지 기억이 안 난다. 그런데 기분이 좋지 않다.
  오늘은 일찍 들어간다.
```

```
여백

  필사하는 동안 무엇을 읽었는지 기억나지 않는다.
  다만, 읽었다는 것은 기억난다.                                   — 1963
```

## 19 · 팔찌

```
적은 해   1988 ~
적은 이   연구원 여럿 · 이름 없음
지금      계속 적는 중
```

### 관찰

모든 구성원은 양 손목에 팔찌가 있다. 집에 들어서면 맺히고, 나서면 흩어진다. 연구원의 팔찌도 같다.

### 결과

- 이음매가 없다. 안쪽에도, 바깥쪽에도
- 무게는 잴 때마다 같다. 다른 팔찌와도 같다
- 충전한 기록이 없다. 꺼진 적도 없다
- 모래가 모여 팔찌가 맺히는 데 걸리는 시간은 사람마다 다르다. 오래 다닌 사람일수록 빠르다는 말이 있다
- 빛깔이 검다. 오래 들여다보면 안쪽이 깊어진다. 들여다본 사람 몇이 어지럼을 호소했다
- 연구원의 팔찌는 **아무 소리도 내지 않는다.** 판으로도 무기로도 바뀌지 않는다. 청구가 승인된 적이 없어서라고 한다
- 판으로 바뀐 것을 서고 안에서 본 조사관의 말로는, 귀환 지점이 **「현 위치」**로 뜬다

### 결론

모른다. 과학으로는 안 된다는 것만 알겠다.

```
적은 이의 말

  1990. 내 팔찌를 오래 들여다봤다. 조용했다. 팔찌가 나를 모르는 척하는 것 같았다.
  조사관 말로는 서고 안에서 판을 켜면 「귀환 지점: 현 위치」가 뜬다고 한다.
  나는 이미 돌아와 있다는 뜻이다. 그런데 왜 그 말이 위로처럼 들렸을까.
```

```
여백

  돌아올 자리가 늘 여기라면, 우리는 여기서 떠난 적이 있는가.     — 연도 없음
```

## 20 · 머릿속의 브리핑

```
적은 해   1986 ~
적은 이   연구원 여럿 · 대응요원과 조사관에게 들은 이야기
지금      들은 이야기 · 계속
```

### 들은 것

과거에 간 요원은 므네모시네의 지령을 머릿속에서 듣는다. 이어폰 같은 것이 아니라고 다들 말한다. 생각이 떠오르는 자리에서 들린다고 한다.
공식적으로 므네모시네는 평가관이 적은 작전을 그대로 읽는다.

- 1986년, 대응요원 한 사람이 브리핑 끝에 평가관이 적지 않은 한 문장을 들었다. 「그 골목은 피하십시오.」 그는 피했다
- 조사관 몇이 귀환 지점이 뜨기 직전에 짧은 정적을 들었다고 했다. 무언가를 고르는 것 같은 정적
- 머릿속의 목소리는 언제나 혼자 듣는다. 그래서 과거에서 들은 것은 무엇이든 대조할 수 없다

### 결론

평가관이 적은 것과 머릿속에서 들린 것이 다른 적이 있다. 공식 기록에는 평가관이 적은 것만 남는다.

```
적은 이의 말

  1986. 그는 웃으며 말했지만 손이 떨렸다.
  피하라고 한 게 누구였는지 묻지 못했다.
  고맙다고 해야 하나, 무서워해야 하나.

  1988. 머릿속에서 들리는 목소리를 우리는 보통 다른 이름으로 부른다.
  여기서는 지령이라고 부른다. 그게 다행인지 모르겠다.
```

```
여백

  그 골목에서 무슨 일이 있었는지 아무도 모른다.
  피했기 때문에.                                              — 연도 없음
```

## 21 · 검은 줄

```
적은 해   1959 ~
적은 이   연구원 여럿 · 이름 없음
지금      계속 적는 중
```

### 관찰

문을 나서면 업무의 기억에 검은 줄이 그어진다. 자기가 누군지, 출근했는지, 누구와 점심을 먹었는지는 남는다. 무엇을 했는지만 사라진다.

### 방법

연구원 둘이 퇴근 직전 서로에게 오늘 한 일을 말해 둔다. 다음 날 문 밖에서 만나 무엇이 남았는지 서로 적는다. 문 안에 들어와서 그 종이를 다시 읽는다.

### 결과

- 문 밖에서 적은 종이에는 「무언가 중요한 일을 했다」, 「둘 다 피곤했다」, 「점심은 국수」 같은 것만 있다
- 문 안에서 다시 읽으면, 빠진 자리가 어디인지 정확히 보인다. 빈칸이 줄을 맞춰 나 있다
- 문 밖에서 업무를 떠올리려 하면 **두통이 온다는 진술이 많다.** 오래 하면 우울해진다는 진술도 있다
- 문 안에서는 아무렇지 않다
- 팔찌가 흩어지는 동안 기억도 같은 빠르기로 흐려진다. 모래가 다 떨어지면 줄이 다 그어진다

### 결론

검은 줄은 지워진 것이 아니라 가려진 것이다. 문 안에서는 걷힌다. 왜 그런지는 모른다.

```
적은 이의 말

  1959. 집에 가서 아내가 오늘 뭐 했냐고 물었다.
  「중요한 일」이라고 했다. 거짓말이 아닌데 거짓말 같았다.

  1974. 문 밖의 나는 문 안의 나를 부러워한다.
  문 안의 나는 문 밖의 나를 걱정한다. 둘 다 나다.
```

```
여백

  문 밖에서 아픈 사람에게 해 줄 수 있는 게 없다.
  문 밖에서는 우리도 왜 아픈지 모르니까.                         — 1981
    그래서 문 안에서 더 잘해 줘야 한다.                          — 연도 없음
```

## 22 · 하나의 말

```
적은 해   1962 ~ 1964
적은 이   연구원 둘 · 각 지부 요원들이 도움
지금      끝남 · 결론 없음
```

### 관찰

너머의 집 안에서는 번역이 필요 없다. 누가 무슨 말로 말해도 알아듣고, 누가 무슨 글자로 적어도 읽힌다.

### 방법

서로 다른 나라에서 출근한 요원 넷이 각자의 말로 같은 문장을 적는다. 문 안에서 서로 읽는다. 그 종이를 문 밖에서 다시 읽는다.

### 결과

- 문 안에서는 넷 모두 넷의 종이를 읽었다
- 문 밖에서는 자기 글자로 적힌 종이만 읽혔다
- 문 안에서 말할 때 자기가 어느 말로 말하고 있는지는 모두가 「내 말로」라고 답했다. 듣는 쪽도 「내 말로 들렸다」고 답했다

### 결론

안에서는 말이 하나다. 무엇이 하나로 만드는지는 모른다.

```
적은 이의 말

  1963. 오늘 처음 만난 동료와 한 시간을 웃었다.
  밖에 나와 보니 그가 어느 나라 사람인지 모른다.
  안에서는 그런 걸 물을 필요가 없었다.
```

```
여백

  모두 다른 곳에서 온다. 여기서는 하나다.                         — 연도 없음
```
