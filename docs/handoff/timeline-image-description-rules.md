# 자료·탐구 이미지 설명 작성 기준

2026-10-31 사용자 지시. 메인 노드와 시대(기간) 노드에 이미 삽입된 이미지 및 앞으로 추가할 이미지에 적용한다.

## 사용자가 정한 기준

1. 자료·탐구 탭 이미지의 설명은 교과서 내용을 근거로 작성한다. 교과서에 근거로 할 내용이 없으면 역사적 사실을 직접 검색해서 찾아 넣는다.
2. 전문 자료와 전문가의 최신 사학계 연구 내용을 검토해 반영한다.

## 작성과 확인 절차

- 실제 이미지, 이미지가 속한 노드, 교과서의 해당 도판과 본문을 함께 확인한다. 파일명이나 짧은 제목만 보고 세부 사항을 추측하지 않는다.
- 해당 교과서에서 확인한 대상·시기·내용·의미를 중심으로, 학생이 이미지를 이해하는 데 필요한 설명을 작성한다.
- 교과서만으로 설명할 수 없는 사항은 전문기관의 소장품 해설, 발굴·조사 보고서, 사료 데이터베이스, 역사 연구자의 학술논문·연구서 등을 직접 검색하고 원문을 확인한다. 검색 결과 요약만으로 근거를 확정하지 않는다.
- 국내 역사 자료는 국사편찬위원회, 한국학중앙연구원, 국립박물관, 국가유산 관련 전문기관 등을 우선 검토한다. 세계사는 해당 지역의 전문 박물관·기록관·대학·학술기관 자료도 검토한다. 기관의 권위만으로 개별 설명의 정확성을 보장하지는 않는다.
- 최근 연구는 발행·개정 시점과 연구자의 전문 분야를 확인한다. 오래된 설명이 수정되었는지 살피되, 최신이라는 이유만으로 단일 연구의 가설을 학계의 합의로 쓰지 않는다.
- 연구 간 이견이 있거나 교과서와 해석이 다르면 근거와 학계 수용 정도를 대조한다. 확인된 사실과 해석을 구분하고, 결론을 확인하지 못한 내용은 보류한다.
- 사진·유물은 식별·용도·역사적 맥락을 설명한다. 지도는 표시된 시기·범례·범위를, 도표·통계는 단위·대상·기간을 확인한다. 이미지에 없는 세부 사항이나 통계가 뒷받침하지 않는 인과관계를 덧붙이지 않는다.
- 같은 이미지가 여러 메인·기간 노드에 있으면 기본 사실은 일치시키되 각 노드와의 관련성을 설명한다.

## 데이터와 출처 관리

- 자료 도판의 설명은 `artifacts[].note`, 탐구의 해설은 `sources[].gloss` 등 기존 화면이 지원하는 필드를 사용한다. 짧은 이미지 제목과 설명을 구분한다.
- 근거는 추적할 수 있도록 해당 항목의 메타데이터나 작업 문서에 제목·해당 쪽/항목·URL·발행/개정 시점(확인 가능한 경우)·확인일을 남긴다. 개인 경로와 비공개 원본은 공개 저장소에 넣지 않는다.
- 기존 규칙대로 화면에 교과서명·쪽수·출처 꼬리표를 표시하지 않는다. 메타데이터를 추가할 때도 화면에 노출되는지 확인한다.
- 데이터 수정은 `timeline-content.js`와 `index.html`에 동일하게 적용한다. 요약(`notes`)과 가상 연구원 기록은 이 작업을 이유로 임의 변경하지 않는다.
- 변경 후 데이터 일치 검사와 정리본 보존 감사를 실시하고, 변경한 자료·탐구 탭을 연구원·대응요원 두 모드에서 확인한다.

## 이 문서의 상태

이 문서는 작성 기준을 정한 것이다. 기존 이미지 설명 전체의 교과서 대조나 최신 연구 검토가 완료되었다는 뜻은 아니다. 항목별 실제 검토 결과와 남은 작업은 별도로 기록한다.
