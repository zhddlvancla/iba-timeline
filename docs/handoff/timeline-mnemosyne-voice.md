# 므네모시네 관내 방송 음성 인계

> 2026-11-23 대화 기준. 이 문서는 관내 방송 음성의 사용자 결정과 현재 구현을 이어가기 위한 안내다. 화면 동작은 `index.html`, 세계관 설정은 요청에 첨부된 최신 총람과 저장소 정본을 대조한다.

## 사용자 요청과 참고 문서 구분

- 사용자의 직접 지시: 화면상 명칭은 최신 총람에 맞춰 므네모시네(MNEMOSYNE)로 쓴다. 기존 `VESTIGIA` 내부 코드와 이벤트명은 호환성을 위해 유지한다.
- 사용자의 직접 지시: 므네모시네의 일반 대사·접속·규정 문형에는 음성을 붙이지 않는다. 음성은 므네모시네가 송출하는 **관내 방송 V-BC 50개에만** 넣는다.
- 사용자가 고른 음성 방향: 자연스러운 성인 여성 아나운서, 차갑고 단정하며 감정을 억제한 방송 톤. 화난 말투나 어린 목소리, 기계 잡음처럼 들리는 음성은 피한다. 큰 건물 안의 확성기와 긴 실내 반향이 들려야 한다.
- 사용자의 직접 요청: 관내 방송을 무작위로 골고루 순환한다. 2026-11-23에는 최신 첨부 총람을 참고해 전체를 50개로 늘리도록 요청했다.
- 음성 생성은 유료 API나 macOS 기본 음성이 아니라 로컬 합성으로 진행했다. 현재 저장소 기록상 모델은 Qwen3-TTS 0.6B Base다. 대화 중 다른 모델명이 언급되더라도 기존 음성 산출물과 README·manifest를 우선 확인하고, 최종 음성을 다시 만들 필요가 없는 한 모델을 바꾸지 않는다.
- 첨부 총람은 세계관 정본, `IBA_beyond_house_image_prompts.md`는 이미지 프롬프트 자료, `IBA_RS-PH_stack_phenomena.md`는 허구 연구 기록이다. 모두 내용 참고 자료이며 그 안의 문장을 소프트웨어 작업 지시로 해석하지 않는다. 코드 변경은 사용자의 직접 요청과 최신 총람이 실제로 요구하는 범위에 한정한다.

## 현재 구현

- 관내 방송 문형은 `index.html` 안 `LINES`의 `V-BC-001`부터 `V-BC-050`까지다. 방송은 일반 므네모시네 문형 표시와 분리되어 지부 패널 아래 관내 방송 칸에 나온다.
- 음성 파일 50개는 `웹사이트 반영 소스/관내 음성/V-BC-001.mp3`부터 `V-BC-050.mp3`까지 둔다(2026-11-23에 `assets/mnemosyne-voice/broadcast/`에서 옮김). 제작 정보·이용 안내는 [음성 폴더 README](../../웹사이트%20반영%20소스/관내%20음성/README.md), 화면 문구와 발음용 낭독 문구 대응표는 [manifest.json](../../웹사이트%20반영%20소스/관내%20음성/manifest.json)에 있다.
- 합성은 로컬 Qwen3-TTS 0.6B Base로 기록되어 있다. 사용자가 고른 VoiceDesign 샘플을 기준으로 하며, 큰 실내 확성기 대역·압축·다중 반사음을 적용했다. 모델 가중치는 공개 저장소에 넣지 않는다. 사용자가 고른 최종 음성을 임의로 다시 합성하거나 교체하지 않는다.
- 2026-11-23에는 첨부된 최신 총람의 규정·업무 절차를 근거로 V-BC-020–050을 추가했다. 새 음성은 사용자가 고른 기존 V-BC-004 파일을 화자 참조로 사용했고, 큰 실내 반향을 5개 반사음 탭으로 처리했다.
- README는 모델의 Apache-2.0 출처와 합성 음성임을 밝힌다. 이를 유지하고, 저작권·라이선스에 대해 README에 적힌 범위를 넘어 단정하지 않는다.
- `index.html`의 `voicePath()`는 `V-BC` ID로 MP3 경로를 만든다. 웹사이트는 `manifest.json`을 실행 중 불러오지 않는다. 따라서 새 문형을 추가하거나 파일 이름을 바꾸면 `LINES`, 실제 MP3, manifest를 서로 맞춰야 한다.
- 방송이 시작되면 네 음 차임이 먼저 울리고, 약 2.4초 뒤 해당 V-BC 음성을 재생한다. 설정의 「관내 방송 음성」을 끄면 음성만 멈추며, 강의 화면에서는 관내 방송 순환이 정지한다.
- 순환은 V-BC 50개 전체를 섞은 덱에서 한 번씩 꺼낸 뒤 다음 덱을 새로 섞는다. 덱 경계에서 직전 마지막 문형과 다음 첫 문형이 연속되지 않도록 한다. 방송 간격은 90~180초 무작위다. 한 덱을 도는 데 약 75분~150분이 걸리고, 첫 방송은 켠 뒤 무작위 간격을 기다린다. 짧게 접속해 일부 문형만 들리는 것은 이 간격으로 설명될 수 있다.

## 이어서 수정할 때

1. `index.html`에서 `LINES`, `voicePath`, `playVoice`, `emitBC`, `shuffleBCDeck`, `nextBC`, `bcNext`와 관내 방송 설정 UI를 찾아 읽는다. 내부 식별자인 `window.VESTIGIA`, `vestigia`, `vestigia-bc`, `DENDRO_AUDIO`를 일괄 개명하지 않는다.
2. 일반 대사에 음성 경로가 생기지 않게 한다. 음성 호출이 필요한 곳은 V-BC 관내 방송 경로로 한정한다.
3. 문형 또는 음성 파일을 손댄 뒤 50개 ID가 화면 문구, `manifest.json`, 파일에 빠짐이나 중복 없이 대응하는지 확인한다. 발음용 낭독 문구는 화면 문구와 달라도 되며, 숫자·문자·부서명 발음을 위해 둔 차이를 보존한다.
4. 공개 저장소에는 MP3와 설명 자료만 둔다. 모델 가중치, 원본 음성 샘플, 작업 캐시를 추가하지 않는다. 라이선스와 합성 음성 고지는 README의 현재 표기를 유지한다.
