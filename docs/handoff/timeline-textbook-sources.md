# timeline-textbook-sources

> Source textbook PDFs for the timeline-app —教科書 originals under assets/w1/교과서, used to author node 정리/자료/탐구 content

The timeline-app's history content (node NOTES, 자료, 탐구) is authored from the official 교사용 교과서 PDFs stored at `assets/w1/교과서/`. When sourcing or fact-checking node content, pull from these. Two publishers (비상교육 / 미래엔) per subject. Related: [timeline-dialog-images-no-lazy](timeline-dialog-images-no-lazy.md).

**과목별 PDF 구성:**

1. **동아시아 역사 기행** (`동아시아 역사 기행/`)
   - 비상교육: 1-1, 1-2, 2-1, 2-2, 2-3, 2-4, 3-1, 3-2, 3-3, 4-1, 4-2, 4-3 (단원-차시별 12개 PDF)
   - 미래엔: 1단원, 2단원, 3단원, 4단원 (4개 PDF; 2단원이 ~140MB로 가장 큼)

2. **세계사** (`세계사/`)
   - 비상교육: 1-1, 1-2, 1-3, 2-1, 2-2, 2-3, 3-1, 3-2, 3-3, 3-4, 4-1, 4-2, 4-3 (13개 PDF)
   - 미래엔: 1, 2, 3, 4 (4개 PDF)

3. **역사로 탐구하는 현대 세계** (`역사로 탐구하는 현대 세계/`)
   - 비상교육: 1-1, 1-2, 2-1, 2-2, 2-3, 3-1, 3-2, 3-3, 4-1, 4-2, 4-3, 5-1, 5-2, 5-3 (14개 PDF)
   - 미래엔(22개정): 1단원, 2단원, 3단원, 4단원, 5단원 (5개 PDF)

**추가 자료:**
- `세계사 연표(수능특강+천재교육).numbers` — Apple Numbers 연표 파일 (~234MB), 폴더 최상위에 위치. 수능특강 + 천재교육 출처를 합친 세계사 연표.

명명 규칙: 비상교육은 `[비상교육] 고등_<과목>_<단원>-<차시>_교사용 교과서.pdf`, 미래엔은 `미래엔_<과목>_교사용교과서_<단원>.pdf` (현대 세계만 `[교사용교과서] 미래엔_22개정_...` 접두). 모두 파일명에 한글 포함.
